# Cleanup FIles
Hapus file pada spesifik directory berdasarkan rentang waktu menggunakan Python.
<br>
<p>Source code ini dibuat untuk tujuan efisiensi dan automasi pemeliharaan sistem. Pastikan Anda menguji skrip ini pada direktori uji coba terlebih dahulu sebelum menjalankannya pada folder penting. Saya tidak bertanggung jawab atas kehilangan data penting akibat kesalahan pengaturan direktori atau rentang waktu penghapusan. Gunakan dengan bijak dan teliti!</p>

<h3>How to Use</h3>
<p>
  1. Pastikan Python sudah terinstal di perangkat Anda.<br>
  2. Tentukan path/lokasi direktori target yang ingin dibersihkan.<br>
  3. Jalankan script:
</p>
<pre>
  <code>python cleanup.py</code> 
</pre>
<p><i>Catatan: <br>Selalu lakukan pencadangan (backup) data penting Anda secara berkala sebelum menjalankan automasi penghapusan file.</i></p>
